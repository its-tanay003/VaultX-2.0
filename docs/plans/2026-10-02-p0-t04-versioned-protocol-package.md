# P0-T04 Versioned Protocol Package Implementation Plan

> **For Claude / Agent:** REQUIRED SUB-SKILL: Use `superpowers:executing-plans` to implement this plan task-by-task.

**Goal:** Create a versioned (v1), strictly validated JSON Schema (Draft 2020-12) protocol specification for all VaultX 2.0 core entities, capabilities, events, and structured errors; establish automated Rust and TypeScript code generators with staleness guards; build a bidirectional round-trip test harness and breaking change detector.

**Architecture:** A schema-first source-of-truth in `packages/schemas/v1/` drives automated code generation for `@valutx/protocol` (TypeScript) and `valutx-runtime-core` (Rust). Schemas enforce `additionalProperties: false`, strict string length, regex patterns for IDs/hashes, and the canonical capability list from `CONSISTENCY.md`. Protocol envelopes support version negotiation (`1.0.0`). Stale generated code and undeclared breaking schema modifications fail in CI.

**Tech Stack:** JSON Schema Draft 2020-12, `json-schema-to-typescript`, `typify` / `schemafy` (Rust), `ajv` (Draft 2020-12 validation), `vitest` / `cargo test`.

---

## Proposed Codegen & Tooling Architecture (ADR-010 Summary)

- **Source of Truth**: `packages/schemas/v1/*.json` adhering to JSON Schema Draft 2020-12.
- **TypeScript Generator**: `json-schema-to-typescript` via a dedicated CLI script `pnpm run generate:ts` writing to `packages/protocol/src/generated/types.ts`.
- **Rust Generator**: Automated schema-to-serde code generator using `typify` / procedural generator writing to `crates/runtime-core/src/protocol/generated.rs`.
- **Header Enforcement**: All generated files are stamped with:
  ```text
  // AUTO-GENERATED BY VALUTX CODEGEN - DO NOT EDIT MANUALLY
  // SOURCE: packages/schemas/v1/
  ```
- **CI Staleness Check**: `pnpm run codegen:check` and `cargo test --test protocol_codegen_staleness` re-runs generation in memory / temp and asserts 0 diff against committed files.
- **CI Breaking Change Detector**: `pnpm run schema:check-breaking` ensures existing required properties, enum variants, or tightened constraints cannot change without a major version increment.

2. Add a CI test case simulating a deliberate breaking change to prove the check fails.
