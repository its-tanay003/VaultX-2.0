# VaultX 2.0 System Threat Model

## Primary Assets
1. User Source Code & Git Repositories
2. Developer Credentials & Secret Keys
3. Host Operating System Integrity
4. Audit Trail Integrity

## Threat Actors
- Malicious AI Model Output (Prompt Injection, Confused Deputy)
- Malicious Repositories (Poisoned configurations, malicious lifecycle hooks)
- Compromised Tools & MCP Servers
